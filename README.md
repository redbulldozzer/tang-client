# tang-client

Клиент подготовки и обновления Clevis Tang привязок LUKS. Адреса заменены демонстрационными. Реальные объявления Tang и проверенные отпечатки серверов нужно настроить на собственном тестовом стенде; запуск изменяет систему.

## Происхождение и состояние

Очищенная отдельная копия существующего проекта из рабочего набора владельца. 20 октября 2026 года владелец подтвердил права на свои проекты и разрешил публичную публикацию очищенного кода. Участие ИИ не скрывается; единоличное ручное авторство всех компонентов не заявляется. Лицензия от имени владельца пока не назначалась.

## Очистка

Не включены .env, ключи, пароли, реальные конфиги доступа, рабочие БД, журналы, пользовательские сессии, персональные данные, резервные копии, готовые архивы и зависимости. Адреса и домены заменены примерами example.invalid и 192.0.2.1. В демонстрационных значениях имена сотрудников заменены. Эти значения не являются рабочими endpoint. Для запуска требуется собственная настройка, тестовое окружение и проверка перед изменением системы.

## Проверка этой копии

Синтаксис Python проверен через ast.parse; выполнение инфраструктурных сценариев не проводилось.

Наличие исходников не является обещанием production готовности на любой машине. Оригинальные рабочие проекты не изменялись.
